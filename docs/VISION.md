# German Mentor Vision

## North Star

German Mentor is not a passive lesson viewer. It is a daily German training system where Mila acts as the learner's private trainer, memory, and command center.

The learner should be able to say:

```text
Mila, I am weak in articles.
Mila, teach me apartment words.
Mila, how do I say this sentence in German?
Mila, make a roleplay with HR.
Mila, revise yesterday.
```

Mila turns that request into a structured mission:

```text
Mistake -> Tiny rule -> Recall -> Speak -> Roleplay -> Save to notebook
```

## Product Formula

```text
Lessons give structure.
Mila gives freedom and decisions.
Notebook gives memory.
Roleplay gives real conversation.
Mistakes become future missions.
```

## Mila's Role

Mila is:

- private trainer
- memory interface
- assignment planner
- grammar explainer
- confidence coach
- command center for revision

Mila is not:

- a mascot only
- a passive guide
- a roleplay actor
- the shop assistant, landlord, HR manager, or doctor

Roleplay characters such as Lisa, Lena, a clerk, landlord, doctor, or HR manager perform the scene. Mila chooses the mission, watches, hints, and reviews.

## Learning Promise

The app should help a Telugu/English-speaking beginner become comfortable using German in daily life, work, and relationships.

The target is not only exam passing. The target is usable German:

- understand simple German
- speak without freezing
- write useful messages
- read everyday text
- handle shopping, appointments, apartments, work, and social situations
- build relationships with German-speaking people

## Local-First MVP Principle

Before adding real AI, backend, Supabase, Deepgram, or external APIs, the app must prove the training loop locally:

```text
Mila creates assignment
-> learner practices
-> learner makes mistake
-> mistake becomes mission
-> mission appears in Today and Notebook
-> Mila reuses weak area tomorrow
```

Real AI should be added later on top of this structure, not instead of it.

## Mission-First Product Shape

The beginner experience should not start as a form or button wall. Today should feel like Mila has already prepared the learner's next tiny step.

Default daily shape:

```text
One clear mission
One Start mission button
One weakness Mila is repairing
One notebook memory created at the end
```

The full trainer command center remains part of the long-term vision, but the first polished learner experience should be calmer:

```text
Today: Mila prescribes
Practice: learner recalls
Speaking: learner says it
Roleplay: learner applies it
Review: mistake becomes memory
Notebook: mission is saved for review
```

## First Polished Mission

The first complete mission is:

```text
Clothing shop: Ask for a sweater in size M.
```

Content:

- weak word: der Pullover
- key phrase: Ich suche einen Pullover in Groesse M.
- tiny rule: after suchen, masculine der becomes einen
- light payment phrase: mit der Karte
- roleplay actor: store assistant Lisa
- Mila role: coach, hint giver, and reviewer
